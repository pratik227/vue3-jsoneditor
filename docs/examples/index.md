# Examples

Live demos with copyable source. Each demo is a small single-file component you can paste into your app.

- <span class="i-solar-code-square-bold-duotone"></span> [Basic Usage](/examples/basic): a minimal two-way bound editor with `v-model`.
- <span class="i-solar-eye-bold-duotone"></span> [Read-only Viewer](/examples/read-only): browse JSON in `view` mode, or lock individual fields with `onEditable`.
- <span class="i-solar-checklist-minimalistic-bold-duotone"></span> [Form Mode](/examples/form-mode): edit values while keeping the structure locked.
- <span class="i-solar-shield-check-bold-duotone"></span> [JSON Schema Validation](/examples/json-schema): validate against a schema and show live errors.
- <span class="i-solar-pallete-2-bold-duotone"></span> [Custom Theme](/examples/custom-theme): brand colors with `--vje-*` CSS variables.
- <span class="i-solar-database-bold-duotone"></span> [Large JSON](/examples/large-json): 5,000 records with `code` mode and `shallowRef`.
- <span class="i-solar-widget-add-bold-duotone"></span> [Custom Toolbar](/examples/custom-toolbar): add Copy JSON and Download buttons with the `#toolbar` slot.

Want to try every prop at once? Open the [Playground](/playground).
